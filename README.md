# Kathirvel M - Modern Portfolio

Modern React portfolio for Kathirvel M.

## Run in VS Code

```powershell
npm install --legacy-peer-deps
npm start
```

Open http://localhost:3000

## Latest changes

- Profile photo moved to the navbar beside Kathirvel M's name.
- Removed the large profile-photo hero module.
- Three project cards are displayed in a responsive grid.
- Certificate cards open a view-only preview modal.
- Infosys Springboard opens as an 8-certificate gallery.
- Masai, Full Stack Python, and G20 certificates use their supplied certificate images in the same preview viewer.
- Certificate images use contain-fit so landscape and portrait certificates are fully visible without distortion.
- Certificate download controls are not provided; browser-level screenshot prevention cannot be guaranteed, so the viewer uses best-effort deterrents.
